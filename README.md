One status update, in the voice of a lost sock that escaped the dryer only to end up somewhere worse:

> "Status update: I escaped the dryer and now live in the cat's mouth. Tell my partner I miss him. Mostly the foot."

## How it works

`main.ts` is a small deterministic Node program. It holds the single entry line, checks that it is 1–120 characters (throwing otherwise), then writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no randomness — every run produces the same file.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
